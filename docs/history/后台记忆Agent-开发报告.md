# 后台记忆Agent-开发报告（工程整理版）

来源：`outputs/后台记忆Agent-开发报告.md`（只读原项目相对路径，非本包附件）。

早期实现把主聊天与后台 Memory Agent 分开：主模型交流、检索并提交建议；worker 从用户原文核实后追加并保存版本。队列处理为单进程单线程，不能泛化为多进程事务安全或可靠 exactly-once。

长时间 POST 锁被拆开以避免模型调用阻塞整个本地服务；聊天返回、任务受理、任务完成和版本改变是不同状态。saved/noop 不等于新增持久事实。

自建 worker 与 Letta 原生 Dreaming 分别报告。8787 早期在线后台状态不代表 8788 已启用更新，更不证明新 v1 HTTP writer 已完成；来源、版本及失败窗口详见 v1 方法契约。
