# 记忆回测-推荐提示词-v2（工程整理版）

> 脱离个人数据的新开发资料副本（2026-10-25）。本文从原报告整理工程结论，非逐字全文副本；删去个人原话、案例过程、模型回答、证据摘录、截图、运行数据及旧校验清单。所有“原报告记录”的结果仅描述历史，不构成本包复验或验收通过证明。

来源：`outputs/记忆回测-推荐提示词-v2.md`（只读原项目相对路径，非本包附件）。

此文件是早期全量重写式记忆提示候选，不是正式 8788 append-only 提示。原候选要求按批保留旧条目、合并新事实、引用来源、区分事实与助手上下文，输出 memory_markdown JSON。

原提示硬编码了开发集人名示例并设约 16000 字符压缩目标。本副本不复制这些名字、具体 source ID 或将容量目标升级为产品规则。相关工程教训是：通用规则不含测试实体，预算不足时明确失败或另定义生成策略，不能静默删重要信息。

正式 v1 的精确无个人内容提示见 docs/v1/summary-method/prompts.json；本文件只保存候选的来源和已发现限制，不能直接作为产品默认 prompt。

当前路线及完整资料导航见[资料索引](../资料索引.md)。
