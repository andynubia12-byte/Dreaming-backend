## 必须保留的更正

1. 早期完整系统回测的搜索虽执行却未回传有效 findings，因此该轮不能证明检索增益。后续修好机械回传，也不自动证明相关性或质量。
2. 稳定层来源可解析不等于句义成立，assistant 线索/临时状态仍可能污染；部分历史 A/B 有未来/自题泄漏，不能当独立无泄漏验证。
3. 旧维护 v2 “全部通过/严重零”被独立语义反例推翻；输入 hash 和 checkpoint 完整不能替代语义判读。后续修复不改旧失败。
4. 缺账不是零次，失去聚合 usage 后必须 unknown；客户端调用、CLI invocation、HTTP传输与计费请求分开，不把缺 usage 当免费。
5. 发布后的摘要可能来自引用再生成，trace 第一次响应未必等于最终发布文本；必须核实际版本，不拿旧响应冒充。
6. 初版流式漏掉 XML 伪调用，原准入撤回。最终坏答案不提交，旧污染在读取侧隔离；原报告里的通过数只属于相应时间/代码。
7. 多模型固定摘要比较没有开放检索工具时，只能比较摘要输入条件，不能推断主模型主动检索意愿或端到端效果。
8. 同日早期说明称双协议/Key仅进程内，已被统一Responses/Keychain的后续修正覆盖；旧历史章节不得覆盖最新事实。
