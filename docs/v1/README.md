## 系统组成与职责

| 组件 | v1 采用的职责 | 当前边界 |
|---|---|---|
| 常驻记忆 | 稳定层 + 事件层全文，主模型开口前理解背景 | 本包不带个人样本，不自动生成 |
| 近期对话 | 仅当前 conversation_id 的近期消息 | 默认 40 条消息、约 60k 估算 token；不是 40 轮 |
| 主聊天 | 理解本轮意图，必要时调用 delegate_memory | 模型独立配置；必须真的传递 tools 才能观察主动检索 |
| 独立检索 | 查原文、日期、细节、矛盾和摘要缺口 | memory-retrieval-agent/2.0；组件编号不等于摘要路线 |
| 摘要生成与后续更新 | 按 8788 方法重建接口化能力 | 显式 v1 HTTP 已接入初始化、追加和稳定层刷新 |
| 版本、任务与来源 | 保存全文、前版、来源、差异和真实任务状态 | 两层与当前指针在 SQLite 原子发布；版本冲突保护，长期质量仍待评估 |

```text
客户端提交 conversation_id + message
  → 后端确定本轮唯一 now（Asia/Shanghai）并保存用户消息
  → 组装稳定层 + 事件层全文 + 当前会话近期消息
  → 主聊天 Responses 请求
       ├─ 直接回答
       └─ delegate_memory（缺口/关键词/实体/时间/已知）
            → 独立检索 Agent → search_history / read_message / expand
            → 分类 findings + 已物化原文 evidence + source_ids + gaps
            → function_call_output 按 call_id 交回同一主模型链
  → 保存完整合格回答 → answer_complete
  → 若启用摘要维护：v1追加事件；旧引擎仍明确分开
  → run_complete
```

## 记忆生成与使用原则

- 保留有证据的重要人物、经历、观点变化及明确偏好，不把详细背景压成短标签；重要性不是词频或情绪强度。
- 事件层从空种子按时间批次追加，保留来源、日期、纠正和状态演变。稳定层独立检索归纳长期背景、明确交流偏好、带时点状态和未知。
- 用户自述、助手历史解释、计划、执行结果和新推断分开。可解析引用不代表原话支持整句措辞；相对时间锚定原消息，不将过期计划变成已完成。
- 完整输入超预算应明确失败，不能静默截断重要材料；失败保留前版完整记忆。追加式方法的长期增长没有因此解决。
- 聊天、摘要生成与检索各用独立 profile、预算及上下文。当前接入使用 Responses；旧生成脚本的历史传输不应成为重新引入旧协议的理由。
- 工具调用及结果使用原生协议，保留协议必需的 reasoning items，但不公开明文思考或凭据。XML/DSML 文本不构成执行工具。
- 日常分享、倾诉、讨论与寻求建议应区别对待。事实是理解依据，推断明确标记；回复风格按本轮意图和用户偏好调整。

## 现有接口如何用于 v1

现有工作台支持自定义完整 memory.text、开启当前检索并禁用旧维护。因此可在拥有合法自有记忆和原文后，先接入“固定摘要 + 当前检索”的聊天。自定义全文不会导入原文或切换来源数据库；创建会话会冻结服务端绑定的历史视图，见接口说明。

新建可成长记忆 workspace 使用 `summary.engine="v1"`、`memory.mode="none"`。`summary.enabled` 只控制聊天后自动事件追加；即使为 false，也可手动提交初始化/追加/稳定层任务，已发布版本仍按 memory.enabled 注入。旧客户端不指定引擎时保持旧 v2.6 行为，不能混写。

前端对接任务提交、run SSE、完整版本读取与冲突提示的示例见 [摘要写入 API](interfaces/摘要写入API.md)。稳定层通过显式任务刷新，不每轮自动重写；不提供跨设备冲突合并或无限历史自动调度。

## 交接状态

- 2026-10-23 的正式决策固定了方法路线；不是对每条个人事实、跨用户泛化或整体聊天质量的无条件认可。
- 历史生成脚本的来源、时间、发布问题保留在方法契约。新引擎增加来源/角色/时间/结构检查与事务发布，但这些机械检查不能证明自然语言推断全部正确。
- 旧摘要对照只注入固定全文的批次不能作为主动检索或端到端效果的证据。工程测试和模型评分不能代替事实支持与真实体验核对。
- Mac/iPhone 原生客户端、iCloud 同步、远程鉴权、多用户隔离、可靠长期 Dreaming 仍未完成。
- 本次未调用模型 API、修改源项目或改变 demo。文档检查与新副本空数据启动验证的范围分别见根目录 PACKAGING.md 和两个整理报告。
