# Dreaming-backend

个人长期记忆 AI 聊天工具的后端开发项目。整理日期：2026-10-25（Asia/Shanghai）。

选定的产品 v1 路线是 **8788 的事件摘要生成方法 + 稳定记忆层原则 + 当前独立检索 Agent**。目标是保留具体经历、重要关系、明确偏好和状态变化，让新对话能正确理解过去与现在；不以拟合某个模型的语言风格为目标。

本目录汇集可开发的聊天/检索/模型/评测代码、现有接口文档、摘要生成参考实现、工程进度与设计资料。没有复制个人历史聊天、生成的个人记忆、批测回答、数据库、凭据或运行日志。原项目与 8787/8788/8789/8791 demo 保持原状。

## 启动

使用 Python 3.11 或更新版本，在本目录执行：

```sh
bash scripts/start-local.sh
```

默认地址为 `http://127.0.0.1:8794/workbench`，避免占用原有 demo 的端口。首次启动没有个人记忆和历史记录；模型推理仍需在新模型池中配置凭据或显式使用环境变量。空数据服务启动不需要推理调用。

## 现在已经能复用什么

- 会话、消息、完整上下文组装及 Responses 模型请求。
- 独立记忆检索 Agent：查找历史、读取原文、扩展上下文、把证据交回主模型。
- 流式回答、工具和 Agent 事件显示、会话管理与模型池。
- 多模型控制变量批测、请求记录、结果报告及隔离数据目录。
- 历史数据导入程序和数据库结构；本包不含导入后的个人数据。

## v1 摘要写入

已新增 **初始化事件摘要、增量追加、独立刷新稳定层** 的统一 HTTP 接口，并接入当前聊天的完整记忆注入。显式使用 `summary.engine="v1"`；`summary.enabled` 控制聊天后自动追加，关闭不影响读取已生成的记忆。旧请求缺省保持旧维护行为，不应以旧开关代替引擎选择。

接口与可复制示例见 [摘要写入 API](docs/v1/interfaces/摘要写入API.md)。任务和工具过程复用 run/SSE；摘要调用独立配置和计费预算。事件层、稳定层、组合全文在 SQLite 中按版本原子发布；错误/截断/冲突保留前版，重启不自动重发收费推理。

本轮验证使用合成来源与本地替代的模型响应，没有导入个人历史或调用真实供应商。工程链路通过不等于已经验证真实模型的记忆质量。

新前端、Mac/iPhone 原生客户端与 iCloud 同步仍属于后续开发；旧批量后维护不自动使用 v1。
